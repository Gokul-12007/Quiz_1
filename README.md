# Redline Quiz

Open `index.html` directly in a modern desktop browser. No server or internet connection is needed.

## Excel format

Use the first worksheet with this exact header row:

`Question | Option 1 | Option 2 | Option 3 | Option 4 | Answer`

`Answer` must be the number 1 through 4. Blank rows are ignored. Download the included template from the Upload screen, or use `questions.xlsx`.

## Controls

- `1`–`4`: answer options; `X`: pass; `N`: next; `Ctrl+Z`: undo
- `F`: fullscreen; `P`: presenter mode; `M`: mute

Progress, teams, and scores are saved in localStorage. Use **New quiz** to clear the current game.
